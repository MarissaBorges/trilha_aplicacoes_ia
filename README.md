## 📌 Descrição

Este repositório é o meu diário de bordo e portfólio da **Trilha de Desenvolvimento de Aplicações com Inteligência Artificial** da **Asimov Academy**. Aqui, documento meu progresso, projetos e aprendizados em cada um dos cursos, construindo uma base sólida para a criação de soluções de IA completas e robustas, desde a integração com APIs até a criação de interfaces web e agentes autônomos.

---

## 📚 Cursos da Trilha

A trilha é composta por módulos que se complementam, formando um ecossistema completo para o desenvolvimento de aplicações de IA.

### 1. API para Iniciantes

O ponto de partida essencial. Neste curso, aprendi os conceitos fundamentais sobre **APIs (Application Programming Interfaces)**, como elas funcionam, como fazer requisições, tratar respostas e integrar serviços de terceiros em aplicações Python. Esta é a base para conectar nossas IAs com o mundo.

---

### 2. LangChain: Orquestrando LLMs

Aqui, mergulhei no **LangChain**, o framework que trabalha com Modelos de Linguagem (LLMs). Aprendi a criar cadeias (chains) para automatizar fluxos de trabalho, gerenciar prompts, conectar a fontes de dados e construir a lógica por trás de aplicações de IA complexas, como sistemas de **RAG (Retrieval-Augmented Generation)**.

---

### 3. Streamlit: Criando Web Apps com Python

Com a lógica da IA construída, o próximo passo é criar uma interface para o usuário. Neste módulo, aprendi a usar o **Streamlit** para desenvolver web apps interativos e elegantes de forma rápida e inteiramente em Python. É a ferramenta perfeita para prototipar e demonstrar o poder das aplicações de IA que desenvolvemos.

---

### 4. Agents: Desenvolvendo Agentes de IA Autônomos

O módulo mais avançado da trilha. Aqui, explorei o conceito de **Agentes de IA**, que são sistemas autônomos capazes de usar ferramentas (como a busca na web, APIs, etc.) para tomar decisões e executar tarefas complexas. Aprendi a construir agentes com LangChain que podem raciocinar e interagir com o ambiente para atingir um objetivo.

---

## 🎓 Habilidades Desenvolvidas

Ao final desta trilha, terei consolidado conhecimentos em:

- **Consumo e Integração de APIs:** Conectar aplicações a fontes de dados e serviços externos.
- **Engenharia de Prompt:** Criar instruções eficazes para extrair o melhor dos modelos de linguagem.
- **Orquestração de LLMs com LangChain:** Construir cadeias complexas, gerenciar memória e implementar sistemas RAG.
- **Desenvolvimento Web com Streamlit:** Criar interfaces de usuário ricas e interativas para aplicações de IA.
- **Criação de Agentes Autônomos:** Desenvolver IAs que podem usar ferramentas para resolver problemas de forma independente.
- **Arquitetura de Aplicações de IA:** Entender como conectar o back-end (LangChain) com o front-end (Streamlit) para criar um produto final coeso.
